# DealerOS

DealerOS is a quantitative options intelligence platform designed to provide
institutional-grade dealer positioning, probability analysis, and market
regime detection for NQ futures traders.

## Mission

DealerOS is not designed to replace order flow.

It exists to provide the missing context behind dealer positioning,
risk-neutral expectations, and options market dynamics so that traders
can make better discretionary decisions.
